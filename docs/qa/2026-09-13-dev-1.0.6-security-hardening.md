## 实现范围

- 登录回显改用 React 文本节点，不再把用户名或服务端用户名注入 HTML。
- “记住密码”改为“记住用户名”；认证模块加载及登录读写时都会删除旧
  `webterm-rm-pwd` 明文密码。
- React Router 升级到 7.18.2，Vite 及传递构建依赖更新到无已报告 npm
  audit 漏洞的版本。
- Go 最低工具链提升到 1.26.6；`golang.org/x/crypto` 升级到 0.56.0，
  `golang.org/x/net` 升级到 0.57.0。
- ZMODEM `rz` 上传在检测后立即安全中止并提示使用 SFTP；未验证的文件
  选择与发送入口已移除。`sz` 下载路径保持原状。
- 新增 push/PR 可复用 CI，并要求 tag release 先通过 UI、Go race/vet、
  npm audit 和 govulncheck。
