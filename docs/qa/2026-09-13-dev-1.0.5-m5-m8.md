- M6：按 user/terminal/client 隔离的 presence、15 秒重连 grace、typed control snapshot/delta、Panel Tab 在线设备数；同 terminalID 默认共享输入，无广播按钮。

- M8：真实浏览器性能、24 shell 容量、tmux churn、数据库副本兼容及既有动态视觉矩阵。
