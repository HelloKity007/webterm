## 可复跑入口

```sh
npm --prefix ui ci
xvfb-run -a node scripts/verify-mobile.mjs
```

有图形桌面时可直接运行 Node。使用本机有界面 Chrome，默认路径`/usr/bin/google-chrome`；可用`WEBTERM_QA_CHROME`指定。`WEBTERM_QA_URL`默认`https://192.168.11.87:9444/`，脚本拒绝其他端口并验证health为release-test。输出在`runtime/mobile-qa/<时间戳>/`，可用`WEBTERM_QA_OUTPUT`指定。

前提：测试环境保留用户已验收的8-pane布局，pane5有包括12号在内的超宽会话Tab列表，测试自动登录可用。脚本不会创建/删除会话，不执行远端命令；布局前提不满足应报FAIL，不能跳过并报告PASS。测试连接仍可能触发attach/resize，不能视为已经证明环境namespace隔离。

覆盖：手机8个pane字号相等、阅读区域无横向溢出、真实触摸事件滑动标签并点击12号、无翻页按钮、返回阅读blur、原生模式无白线、3次键盘几何变化模拟恢复、无pageerror。结果包含服务版本、每项断言、截图和NOT RUN清单。
